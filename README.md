# README

Default community health files shared across all repositories under this account.

## About

This repository provides the community health files (license, code of conduct,
security policy, etc.) that apply to every project under this account.

All projects here are **personal, solo-maintained open-source work** — built and
released purely out of passion. They are provided as-is, with no
service-level guarantees, and updated whenever I have the time and interest.

If any of it ends up being useful to someone else, that alone makes the effort
worthwhile.

## Contributions

These projects generally **do not accept external contributions**. Issues and
discussions may be reviewed when time allows, but pull requests will typically
be closed unless the change has been explicitly coordinated in advance.

This is purely a workflow choice — it is not a comment on the value of any
contribution — so that I can keep maintenance sustainable as a single
developer.
