# Security Policy

## Supported Versions

Security patches are applied to the latest release only.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in any of these projects, please
report it responsibly. Email **leonxia@dogitect.io** with:

- Vulnerability description
- Reproduction steps
- Potential impact
- Suggested remediation (optional)

## Response Timeline

These projects are maintained by a single developer in their spare time, so
responses are best-effort:

- **Acknowledgment:** As soon as I see the report
- **Status updates:** Provided as progress is made
- **Credit:** Available in security advisories upon request

## Disclosure Guidelines

- Do not open public issues for security vulnerabilities
- Do not disclose vulnerabilities before a fix is released

Thank you for helping keep these projects secure.
